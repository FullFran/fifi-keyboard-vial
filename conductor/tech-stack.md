# Technology Stack - Fifi Keyboard & Landing Page

## 1. Firmware (QMK/Vial)
*   **Core:** [QMK Firmware](https://qmk.fm/) with [Vial](https://get.vial.today) support.
*   **Language:** C/C++.
*   **Key Features:** Real-time configuration, Combos, Tap Dance, Auto Shift, OLED support.

## 2. Hardware
*   **MCU:** RP2040 (via Michi Pro Micro conversion).
*   **Keyboard Layout:** Fifi (3x5+3 split).
*   **Display:** SSD1306 128x32 OLED.
*   **Build Method:** Handwired matrix.

## 3. Landing Page (Frontend)
*   **Framework:** [Astro](https://astro.build/) (v5.x).
*   **Language:** TypeScript.
*   **Components:** Astro components (.astro).
