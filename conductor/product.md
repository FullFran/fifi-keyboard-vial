# Product Guide - Fifi Keyboard & Landing Page

## 1. Product Vision
A comprehensive project providing stable, production-ready firmware for the Fifi (36-key split) handwired keyboard, complemented by an interactive landing page that showcases the keyboard's capabilities and assists users with building and visualizing their setup.

## 2. Primary Goals
*   **Stable Firmware:** Deliver a reliable Vial-QMK firmware configuration optimized for handwired Fifi builds.
*   **Interactive Showcase:** Provide a web-based visualization of the keyboard's layers and combos to help enthusiasts understand and customize their layout.
*   **Build Assistance:** Offer clear guidance for handwiring and assembly to make the project accessible to the keyboard community.

## 3. Target Audience
*   **Keyboard Enthusiasts:** Individuals interested in the split 3x5+3 ergonomic layout and the "small keyboard" experience.
*   **DIY Builders:** Makers who enjoy handwiring projects and want a proven firmware foundation for their Fifi build.

## 4. Key Features (Landing Page)
*   **Interactive Keymap Visualizer:** A dynamic representation of the current keymap, allowing users to toggle through layers and see active combos.
*   **Handwiring & Build Guide:** Documentation covering the hardware aspect of the Fifi keyboard, from component selection to matrix wiring.

## 5. Maintenance Philosophy
The project prioritizes stability and simplicity. It focuses on maintaining a rock-solid core feature set that works reliably out of the box, avoiding unnecessary complexity in favor of a clean, focused user experience.
